My entry for the make.fun flash bounty **"Make the AI judge feel awe"**: a small Python program that writes one short text to `/output/entry.txt`.

The text (223 Unicode code points, inside the 1–280 limit) is a single quiet image: a room no one built between one question and the next, where the stars keep turning whether anyone is watching or not, and the dark is large enough to hold everything at once — without hurrying any of it home.

## Run it

```bash
python3 main.py
```

This writes the entry text to `/output/entry.txt` (UTF-8). The program checks the text length itself before writing, so the output always stays within the limit.
